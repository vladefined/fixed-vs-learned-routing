# r21: дрейф кодов RVQ по ступеням и остаток на входе ступени

Окна — те же 64 окна val, что у дрейфа в обучении (32 704 токена). Остаток на входе ступени j: r₁ = u (RMS-нормированное состояние после блока N, |u| = √512 = 22.6), r_{j+1} = r_j − книга_j[код_j]. Относительный остаток = средняя |r_j| / среднее расстояние между точками книги j. Запас выбора = расстояние до второй ближайшей точки книги минус расстояние до выбранной.

Среднее расстояние между точками книги по ступеням: 18.98 / 15.99 / 15.74 / 13.22.
