# Адаптивность гейта QG на TinyStories

Сводка всего про адаптивность из раунда 6:
- часть 2 — REPORT 10.6;
- ночной блок — REPORT 10.10;
- метрики, досчитанные на готовых чекпойнтах (без обучения).

Прогоны (20k шагов, общая сетка из 10.4): QG25 s0 и s1, QG35, QG50, QG-split25, QG-split35, QG-split50.

**Постановка.**
- **Токены.** Первые 608 окон val, 311k токенов, одни и те же для всех прогонов.
- **Решение и трудность.**
  - Гейт в позиции t решает по состоянию текущего токена t.
  - Трудность позиции — потеря предсказания токена t+1. Основная опора — потеря A на том же токене.
- **Открытые группы** — сумма по 8 блокам × 8 группам, из 64. «Доля» — та же сумма, делённая на 64.
- **Проверка пересчёта.** Новые числа считал `dd/ts_adapt.py`. Его решения гейта совпали с сохранёнными в
  `tok.npz` на 100%, потери — до округления fp16.
- **Материалы.**
  - Полные таблицы — [`r6_adapt_tables.md`](r6_adapt_tables.md), рисунок — [`r6_adapt.png`](r6_adapt.png).
  - Прежние таблицы — [`r6ts_tables.md`](r6ts_tables.md) и [`r6n_tables.md`](r6n_tables.md).

## Коротко

**Используют ли модели бюджет по-разному в зависимости от контекста — да.** Решение гейта зависит от
контекста, а не только от того, какой токен на входе.

- **Сам токен объясняет только часть.**
  - Текущий токен объясняет 55–61% дисперсии общего числа открытых групп (R² таблицы «токен → решение» на
    отложенных данных). Остальные ~40% зависят от контекста.
  - Если подставить таблицу вместо гейта, качество падает: от +0.12 до +0.51 нат. Решения, зависящие от
    контекста, нужны модели.
- **Связь с трудностью в основном контекстная.**
  - Внутри одного и того же токена ρ(открыто, потеря A) = 0.19–0.24. По всем токенам — 0.26–0.30.
  - Прогноз по одному токену даёт только 0.14–0.16.
- **Контекстный сигнал общий для всех блоков.**
  - При том же токене в одних контекстах модель открывает больше групп сразу во всех блоках.
  - Корреляция числа открытых между блоками внутри токена 0.16–0.28 — почти та же, что без поправки на токен.
  - Поэтому распределение общего числа открытых групп в 3.4–6.6 раза шире, чем у независимых случайных гейтов.
- **Самый сильный контекстный эффект — позиция в истории**, у всех 7 прогонов одинаковый.
  - На первых 5 токенах открыто 0.28 от среднего, на токенах 6–20 — 0.73. С 21-го токена доля выходит
    на среднее.
  - На токенах 6–20 это не следует из трудности: потеря A там 1.45 против 1.40–1.42 дальше.
  - Дело не в объёме контекста. В окнах, которые начинаются посреди истории, на первых 5–20 токенах окна
    QG25 открывает 0.22–0.26 — почти как в среднем, хотя контекста там так же мало. Эффект связан именно с
    началом истории, после EOT.
- **Но связь с трудностью умеренная.**
  - Число открытых групп предсказывает ошибку топ-1 самой модели с AUROC 0.61. Сама потеря A предсказывает
    её с AUROC 0.95.
  - За трудностью следят поздние блоки 5–7 (ρ 0.25–0.36). В блоках 0–1 у QG связи нет (ρ ≈ 0).

**Меняется ли это с ростом доли открытых групп — почти нет.**

- **Сила связи с трудностью не меняется.** ρ ≈ 0.29, AUROC ошибки 0.61, R² по токену 0.55–0.61 при целях
  0.25, 0.35 и 0.5.
- **Относительные различия чуть сглаживаются.**
  - Отношение «самые трудные / самые лёгкие 20%» падает: 1.44–1.49 → 1.36 у QG, 1.40 → 1.34 у QG-split.
  - Отношение «перед редким словом / перед началом предложения»: 2.3–2.5 → 1.6 у QG, 2.0 → 1.4 у QG-split.
  - ρ внутри токена: 0.21–0.24 → 0.20 у QG, 0.20 → 0.19 у QG-split.
  - Добавочные группы ложатся почти равномерно: от QG25 к QG50 на 13 групп больше в самой лёгкой пятой
    части и на 17 — в самой трудной.
- **Распределение становится шире относительно случайного.**
  - Дисперсия на блок: 1.9 → 2.3 бинома у QG, 1.4 → 2.2 у QG-split.
  - Корреляция между блоками: 0.18 → 0.26–0.27.
  - Токены с 0 открытых групп в блоке при цели 0.5 встречаются в 11 раз чаще случайного (6.7% против 0.6%).
- **Подстановка таблицы по токену дешевеет:** +0.36 → +0.12 нат у QG, +0.51 → +0.18 у QG-split. Доля
  решений, угадываемых по токену сверх базы, та же: κ 0.55–0.61.
- **QG и QG-split ведут себя одинаково.** Отличие одно: у QG-split ранние блоки чуть следят за трудностью
  (ρ 0.04–0.10 в блоке 0–1 против ~0 у QG).

Как читать столбцы:
- **«ρ внутри токена»** — Спирмен между отклонениями от среднего по этому токену: числа открытых групп и
  потери A. Связь, которую не объясняет сам токен.
- **«ρ прогноза по токену»** — Спирмен между потерей A и числом открытых групп, предсказанным таблицей по
  одному текущему токену (раздел 5). Связь, которую объясняет сам токен.

Что видно:
- **Сумма по блокам связана с трудностью сильнее, чем каждый блок по отдельности** (0.26–0.30 против
  0.15–0.19 в среднем).
  - Ранние блоки почти не следят за трудностью, поздние следят: блоки 5–7 дают 0.25–0.36 у всех прогонов.
  - Порядок блоков по ρ от сида почти не зависит, хотя доли открытых групп по блокам между сидами разные
    (раздел 6).
- **Связь с трудностью в основном контекстная.**
  - Внутри токена остаётся 0.19–0.24 из 0.26–0.30.
  - Одна таблица по токену даёт 0.14–0.16.
- **С ростом доли** сумма по блокам не меняется, среднее по блокам чуть растёт (у QG 0.16 → 0.19), ρ внутри
  токена чуть падает.

- **Между блоками разброс токеном не объясняется.**
  - Число открытых в разных блоках коррелирует на 0.18–0.27, и внутри токена почти так же: 0.16–0.28.
  - Поэтому сумма по 64 в 3.4–6.6 раза шире бинома, а внутри токена — в 2.2–3.0 раза шире, чем при
    независимых блоках.
  - Это и есть контекстный режим «потратить больше везде»: тот же токен в одном контексте получает больше
    групп во всех блоках сразу.
  - С ростом доли он усиливается: корреляция 0.17 → 0.26.

## 5. Предсказуемость по одному текущему токену (как в r4 и r5 на синтетике)

Как устроена проверка:
- **Таблица «текущий токен → группа открыта»** для каждого блока и группы — большинство по 2000 случайным
  окнам train, ~1M токенов. 99.3% токенов val встречены в train ≥ 5 раз, для остальных берётся доля группы
  в целом.
- **Проверка** — на окнах val.
- **База** — одно решение на группу, без учёта токена.
- **κ** — доля ошибок базы, которую устраняет таблица.
- **Подстановка** — все решения гейта заменены таблицей, ΔCE на тех же 608 окнах.

  стоит.
- **Против базы выигрыш умеренный.** Таблица устраняет 55–61% ошибок базы, и эта доля не зависит от цели.
  Сырые 84–90% выглядят выше в основном из-за того, что при низкой доле открытых групп база уже даёт
  60–77%.
- **Ранние блоки сильнее определяются токеном,** чем поздние.
  - В блоке 0 таблица устраняет 0.63–0.81 ошибок базы, в блоке 7 — 0.29–0.51.
  - Это согласуется с разделом 1: поздние блоки следят за трудностью в контексте.
- **Решения, которые таблица не угадывает, важны.**
  - Подстановка стоит +0.12…+0.51 нат, хотя таблица открывает почти ту же долю групп.
  - Цена падает с ростом доли: меньше закрытых групп — меньше мест для ошибки.
