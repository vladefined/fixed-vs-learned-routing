# Раунд 25: итоговая сборка без обучения (Qwen3-0.6B)

Расход — скалярные произведения длины d на токен в блоке (полный FFN 9216). Учтено всё: двухступенчатый маршрут к одной из 256 групп (32), FFN (3 × ширина; у двухуровневой — TEAL в пуле группы, 3 × пул × доля), поправка (одна карта ранга 32 на блок + сдвиг на группу, 64). С поправкой ширины пересчитаны на бюджет без её 64 единиц. Исходная модель 2.3965, оракул верхней половины при 1/4 (свои 768 у каждого токена) 2.4246. Δ ± 2 SE по окнам val.
