## 2. Причинная проверка на QG50

В каждом блоке у 20% токенов каждого окна закрыта половина открытых гейтом групп (при нечётном числе — с вероятностью ½ на одну больше); выбор групп — случайный среди открытых, у lowgate — с наименьшим логитом гейта. Базовая CE 1.4848; решения гейта в базовом проходе совпадают с tok.npz на 100.0%.
